# Production QA Portfolio – MR YU Case Study

## Project overview

This repository presents manual testing activities completed for MR YU, a live restaurant ordering website built with WordPress and WooCommerce.

The project focused on identifying functional, usability, responsive design, checkout, and payment-flow issues across desktop and mobile devices.

## Website under test

MR YU restaurant website: https://mryu.ro

## Testing scope

- Functional testing
- UI and usability testing
- Responsive testing
- Checkout testing
- Payment-flow testing
- Cross-browser testing
- Regression testing
- Exploratory testing

## Areas tested

- Product menu and categories
- Product pages
- Shopping cart
- Checkout process
- Delivery and pickup options
- Promotional codes
- WhatsApp ordering
- Payment methods
- Mobile navigation
- Responsive layout

## My contribution
